# 記事ガイドライン（POMiE Portal）

記事の目的・書き方・守ること。自動執筆（`/write-article`）も人が書く場合も、このガイドラインに従う。

## 1. 記事の目的

1. 検索で見つけてもらい、**掲載美容師（POMiE の美容師・外部サロンのフリーランス美容師）のページへ送客する**こと
2. 読んだ人の悩みが実際に解決に近づくこと（読まれない記事は検索にも載らない）

この 2 つを満たさない記事は書かない。「とりあえず本数を増やす」はしない。

### 一番の武器は「ここにしか無い情報」

一般的な美容情報は、どのサイトにも書いてある。このサイトにしか書けないのは次の情報で、記事には必ずどれかを組み込む。

- 美容師ごとの **強み・得意メニュー・予約可能メニュー・料金目安**（サイトで公開済みの情報）
- 店舗の **エリア・雰囲気**（表参道／恵比寿）
- 「この悩みなら、この美容師」という**具体的な結びつけ**

## 2. キーワードの選び方

### 記事の軸

**エリア × メニュー × 悩み・目的** を基本にする。

| 軸 | 例 |
|---|---|
| エリア | 表参道、恵比寿、（渋谷・青山などの近隣） |
| メニュー | 髪質改善、縮毛矯正、似合わせカット、ハイライト、白髪ぼかし、メンズカット、ヘッドスパ … |
| 悩み・目的 | くせ毛、広がる、ダメージ、朝の時短、似合う髪型が分からない、ブライダル … |

例：「表参道 髪質改善」「恵比寿 白髪ぼかし 40代」「くせ毛 広がる カット 表参道」

### 選ぶ基準（優先順）

1. **掲載中の美容師が実際に対応できる**こと（得意メニュー・予約可能メニューにある）
2. **予約に近い検索意図**であること（「〜 美容院」「〜 おすすめ」「〜 料金」は近い。「〜とは」は遠い）
3. 月間検索数が **100〜3,000 程度**で、SEO 難易度が高すぎないこと（立ち上げ期は大きい語を狙わない）
4. **既存記事と重ならない**こと（`context.mjs --keyword` で確認）

### ツール

- ラッコキーワード MCP（`suggest-keywords` / `question-search` / `other-keywords`）でサジェスト・検索数・質問を取る
  - ライトプランは **1 回 5 クレジット**。1 記事あたり **15 クレジット以内**を目安にする
  - `search-volume-history` は 1 回最低 50 クレジット消費するため、ユーザーの指示が無い限り使わない
- ラッコが使えないときは WebSearch で Google のサジェスト・関連質問を調べる

## 3. 記事の型

### タイトル

- **32 文字以内**（検索結果で切れない長さ）
- キーワードを**前半**に入れる
- 読む理由が分かる（「〜の選び方」「〜で失敗しない 3 つのポイント」「〜の料金相場と通う頻度」）
- 煽らない。「衝撃」「驚愕」「絶対」は使わない

### 概要（summary）

- **80〜120 文字**。記事一覧のカードと、検索結果の説明文に使われる
- 誰向けで、読むと何が分かるかを書く

### 本文の構成（Markdown）

```
（書き出し：2〜4 文。読者の状況に共感し、この記事で分かることをキーワードを含めて示す）

## 見出し 1（検索意図に直接答える。キーワードを含む）
## 見出し 2
### 小見出し
## 見出し 3
## 美容師に相談するなら（送客セクション）
## よくある質問（2〜4 問。「### Q. 〜？」→ 答え）
## まとめ（3〜5 行＋行動の呼びかけ）
```

- 見出しは `##` から始める（`#` は使わない。タイトルが H1 になる）
- `##` は 3〜6 個。1 見出しあたり 200〜500 文字
- 本文は **2,500〜4,500 文字**が目安（薄い記事は書かない。無駄に長くもしない）
- **表（`|` 区切り）は使わない**。現在のサイトでは表示されないため、箇条書きで書く
- 画像は入れない（カバー画像は管理画面で設定する）
- 「よくある質問」はラッコの `question-search` や検索の関連質問から、実際に聞かれている疑問を選ぶ

### 送客セクション（必須）

記事の終盤に、記事の内容と結びつく美容師を **1〜3 名**紹介し、ページへリンクする。

- **外部美容師**（POMiE と契約していない、他サロンで活動するフリーランス美容師）は、所属サロン名で紹介する。ポミエ（POMiE）の美容師・ポミエ在籍とは書かない
- **予約ボタンがない美容師**（外部美容師でオプションを付けていない人）について「予約できる」「予約はこちら」と書かない。美容師ページ（プロフィール・SNS）への案内にとどめる

```
## 表参道で髪質改善を相談するなら

ポミエ 表参道の [倉持 みゆき](/stylists/st-47e9gf) さんは、髪質改善と縮毛矯正を得意としています。
料金の目安は ¥7,000〜¥20,000。くせや広がりが気になる方は、まずカウンセリングで髪の状態を相談してみてください。

- [表参道の美容師一覧を見る](/stylists?storeId=s1)
- [髪質改善が得意な美容師を探す](/stylists?menu=%E9%AB%AA%E8%B3%AA%E6%94%B9%E5%96%84)
- [4 つの質問で相性のいい美容師を診断する](/match)
```

フロントマターの `related_stylist_ids` にも同じ美容師を入れる（記事の下に美容師カードが出る）。

### 文体

- です・ます調。読者は「あなた」。美容師は「〇〇さん」
- 1 段落は 3 文程度。箇条書きを活用する
- 専門用語は初出で一言説明する（例：「酸熱トリートメント（酸と熱で髪の内部を整えるメニュー）」）
- 断定しすぎない。効果は「〜しやすい」「〜を目指す」「多くの場合」
- 他店・他の美容師を貶めない。比較は一般論にとどめる
- AI っぽい定型句を避ける：「いかがでしたか」「〜について解説します」「〜は重要です」の連発、「結論から言うと」の多用

## 4. 一次情報の扱い（守ること）

### 使ってよい情報

- 美容師ページで**公開済み**の情報：名前、所属店舗、プロフィール文、強み、得意メニュー、予約可能メニューと施術時間、料金目安、Instagram のリンク
- 店舗情報：名前、エリア、キャッチコピー
- `context.mjs` の出力に含まれているものだけ

### してはいけないこと

- 美容師の**発言を作らない**（「〇〇さんは『…』と語ります」は、本人の言葉を実際に得ていない限り書かない）
- 施術例・ビフォーアフター・お客様の声を**創作しない**
- Instagram の投稿文を引用しない（リンクするのは可）
- 公開されていない情報（経歴、年齢、私生活、未公開の料金）を書かない
- 美容師の本名・活動名を、ページの表記と変えない

### 書き方の例

- 可：「ポミエ 表参道の倉持 みゆきさんは、髪質改善と縮毛矯正を得意メニューに挙げています」
- 不可：「倉持さんによると、縮毛矯正は 3 か月に 1 度が理想とのこと」（本人の発言を作っている）

事実として断定できない部分は `[要確認: 内容]` と書いておく。公開前に運営が確認し、マーカーを消す。

## 5. 使ってはいけない表現（薬機法・景表法の目安）

美容分野は、効果・効能の書き方に法律の制限がある。以下は**目安**で、最終判断は運営側で行う。迷ったら弱い表現にする。

| 使わない | 理由 | 言い換え |
|---|---|---|
| 治る・治す・治療・完治 | 医療行為の表現 | 整える、ケアする、扱いやすくする |
| 修復・再生・蘇る | 髪は修復・再生しない | 補修、ケア、ダメージを目立ちにくくする |
| 発毛・育毛・毛が生える | 医薬品の効能 | 頭皮環境を整える、ボリューム感 |
| 永久・半永久・一生・二度と | 持続の断定 | 長く、続きやすい、◯か月が目安 |
| 絶対・必ず・100%・確実に・誰でも | 効果の保証 | 多くの場合、〜しやすい、〜を目指す |
| No.1・日本一・業界初・最安・最高級・唯一 | 根拠のない最上級 | 根拠を示せない限り使わない |
| 副作用なし・安全です | 安全性の断定 | 刺激を抑えた薬剤を選ぶ、事前にパッチテストを行う |
| アンチエイジング・若返り・老化防止 | 老化防止の表現 | 年齢に応じたケア、大人の髪に合わせた |
| 医師・医学的・臨床 | 医療との関連の示唆 | 根拠を示せる場合のみ出典付きで |

`check.mjs` がこれらを検出する（エラーは保存できない）。

## 6. URL とエリア

- 記事の URL は `/articles/{slug}` の 1 階層（エリアを URL に入れない）。後から分類を変えても URL が変わらないようにするため
- `omotesando` / `ebisu` などエリア名の slug は、エリアの記事一覧（`/articles/omotesando`）で使うので記事には使えない
- 記事にはエリア（タグ）を付ける。キーワード・タイトルに地名があればそのエリア、無ければ紹介する美容師の店舗のエリアが自動で付く。
  エリアに関係ない記事（「髪質改善と縮毛矯正の違い」など）は空でよい。変えたいときはフロントマターに `areas: [omotesando]` と書くか、管理画面で変更する
- エリアの記事一覧は、記事が 1 本以上公開されると検索エンジンに登録される（0 本の間は noindex）

## 7. リンク

- サイト内リンクを **2〜5 本**入れる（美容師ページ、一覧の絞り込み、診断、関連記事）
  - 美容師: `/stylists/{id}`
  - メニューで絞った一覧: `/stylists?menu={メニュー名を URL エンコード}`
  - 店舗で絞った一覧: `/stylists?storeId=s1`（表参道）/ `s2`（恵比寿）
  - 診断: `/match`
  - 記事: `/articles/{slug}`（公開済みの記事のみ）
- 外部リンクは **3 本以内**。公的機関・メーカーなど信頼できる出典のみ。https のみ
- リンクの文言は「こちら」ではなく、リンク先が分かる言葉にする

## 8. 自動執筆の記事を公開する前に（運営のチェックリスト）

管理画面のプレビューで確認する。

- [ ] 事実関係：料金・メニュー・店舗名が美容師ページと一致している
- [ ] `[要確認]` を全部確認し、本文から消した
- [ ] 美容師の発言・施術例・お客様の声が創作されていない
- [ ] 表現：法律面で気になる言い回しが無い（上の表）
- [ ] 読んで役に立つか。同じ内容の記事が検索上位に無いか（独自性）
- [ ] タイトル・概要が内容と合っている
- [ ] リンク先が正しいページに飛ぶ
- [ ] 紹介した美容師に、掲載する旨を伝えた（初回のみ）
- [ ] カバー画像を設定した（店舗写真 `/images/stores/…` でも可）
- [ ] エリアが正しい（記事一覧で該当エリアに出したいか）

公開は管理画面で「公開」に切り替えて保存する。**自動執筆の仕組みは公開を行わない。**

## 9. 運用の目安

- 公開後 **1〜3 か月**で Search Console の表示回数・掲載順位を見る
- 表示はあるのにクリックが少ない → タイトル・概要を直す
- 掲載順位 11〜20 位 → 見出しの追加・一次情報の追加でリライト
- 美容師の情報（メニュー・料金）が変わったら、その美容師を紹介している記事も直す
